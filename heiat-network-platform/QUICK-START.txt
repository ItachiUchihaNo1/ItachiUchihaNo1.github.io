راه‌اندازی خیلی خلاصه:

1) cp .env.example .env
2) مقادیر .env را تنظیم کن
3) docker compose up -d db
4) docker compose build app
5) docker compose run --rm app npx prisma db push
6) docker compose run --rm app npm run db:seed
7) docker compose up -d
8) دامنه تعریف‌شده در DOMAIN را باز کن

برای محیط واقعی:
- SMS_PROVIDER=webhook
- SEED_DEMO_DATA=false
- DOMAIN=app.yourdomain.ir
- ADMIN_PHONE=شماره مدیر
