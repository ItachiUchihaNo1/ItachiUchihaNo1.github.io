# پیش‌نیاز جلسه صوتی/تصویری و ضبط

در این بسته سرویس رسانه عملیاتی وجود ندارد؛ هیچ اتاق، token رسانه یا فایل ضبط فرضی ساخته نمی‌شود. cPanel برای صفحات PHP، کنترل دسترسی، زمان‌بندی، DB و متن کافی است؛ به‌تنهایی زیرساخت WebRTC/رسانه، TURN، ضبط سمت سرور و نظارت بر سلامت ضبط فراهم نمی‌کند.

برای انتخاب سرویس لازم است این موارد با مستند و آزمون واقعی تأیید شوند:

- اتاق خصوصی و token کوتاه‌عمر محدود به کاربر، رزرو، زمان و نسل جلسه.
- آغاز انتقال فقط پس از ACK معتبر ضبط سمت سرور؛ تأیید ظاهری مرورگر معتبر نیست.
- قطع انتقال در خود SFU/زیرساخت یا ابطال مؤثر مجوز با قطع ضبط؛ قطع آیکن UI کافی نیست.
- بازیابی ضبط با تأیید جدید، generation و رویداد ترتیبی/امضاشده؛ webhook تکراری یا قدیمی نباید جلسه را باز کند.
- ضبط سمت سرور و ذخیره پایدار خصوصی، کنترل دسترسی و دریافت، یکپارچگی قطعات، وضعیت نهایی و شکست ناقص.
- سیاست نگهداری، حذف مصوب، محل داده، سقف مصرف و هزینه، پشتیبان و بازیابی.
- امکان کار در مرورگر داخلی ایتا، مجوز میکروفون/دوربین و fallback مناسب.

استقرار خودمیزبان چنین سرویسی معمولاً پردازش ماندگار و پورت/منابع بیرون PHP اشتراکی می‌خواهد؛ گزینه دیگر سرویس میزبانی‌شده با این تضمین‌هاست. هیچ‌کدام بدون انتخاب و تأیید نیازمندی و هزینه به پروژه تحمیل نشده است.

آزمون شروع، از دست رفتن ضبط، تأخیر/جعل/replay رویداد، ابطال انتقال و بازیابی باید با سرویس انتخابی انجام شود. آزمون فعلی متن و خطای ذخیره، جایگزین آزمون رسانه نیست. فعلاً رضایت ضبط منتشر نمی‌شود و رزرو عمومی طبق دستور شما بسته است.
