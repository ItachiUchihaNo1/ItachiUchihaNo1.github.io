# وضعیت واقعی بسته اجرایی

این تحویل، سورس قابل نصب برای محیط آزمایشی است. نصب روی cPanel شما، ارسال واقعی پیامک، OAuth واقعی و جلسه صوتی/تصویری انجام نشده‌اند. «بسته سورس» به معنی تأیید تمام الزامات انتشار عمومی نیست.

## پیاده‌سازی متصل به دیتابیس و آزموده‌شده محلی

| بخش | رفتار فعلی |
|---|---|
| معماری | دو Document Root و ورودی مستقل، هسته و دیتابیس مشترک، نشست و مجوزهای مستقل سایت/مدیریت، شش migration، InnoDB و utf8mb4 |
| هویت | OTP با انقضا/مصرف یک‌باره/سقف تلاش، ورود موبایل و رمز، بازیابی و تغییر رمز، اثبات و تغییر شماره بدون ادغام خودکار، شناسه داخلی ثابت، ابطال نشست و حسابرسی |
| مدیریت | ساخت امن اولین مدیر با کلید خصوصی و قفل اتمی، ورود و رمز مستقل، مدیر سامانه/محتوا، مدیریت کاربران و نقش‌ها، بررسی زنده نقش در سرور |
| اتصال خارجی | code flow گوگل، PKCE/state/nonce و بررسی امضای RS256/issuer/audience/time؛ امضای رسمی و تأیید یک‌بارمصرف ایتا؛ اتصال به همان حساب، تعارض مالکیت، احراز مجدد و منع قطع آخرین روش قابل استفاده |
| مرشد | دعوت حساب موجود توسط مدیر، پذیرش شخص با قوانین پایه، بررسی/فعال‌سازی/محدودسازی، پنل شخصی، پروفایل و عکس نیازمند بررسی |
| محتوا | موضوع/مسئله و ارتباط موضوع بالادست، جست‌وجوی فارسی و صفحه‌بندی، فیلتر و مرتب‌سازی، صفحه مرشد و تجربه، اقدام واضح گفت‌وگو |
| تجربه | پیش‌نویس نسخه جدید، کنترل تعارض ویرایش، ارسال، مقایسه قبل/بعد، درخواست اصلاح/رد/تأیید، اشاره‌گر نسخه عمومی و توقف انتشار، مستند عمومی وابسته به نسخه |
| ویترین | بلوک متن/مرشد/تجربه، انتخاب دستی یا خودکار، ترتیب/تکثیر/حذف، زمان‌بندی، پیش‌نویس نسخه‌دار، پیش‌نمایش، انتشار و بازیابی؛ حذف خودکار محتوای غیرقابل انتشار از بلوک‌ها |
| تقویم | مدت، فاصله، حداقل مهلت، ظرفیت روزانه، بازه هفتگی به وقت تهران، تعطیلی، توقف پذیرش، محدودیت سازمان مشترک؛ محاسبه و کنترل سرور |
| رزرو داخلی | ثبت توسط مدیر سامانه، رزرو ظرفیت با قفل تراکنشی، idempotency، پذیرش/رد/انقضا/لغو/پایان، تاریخچه تصمیم، پیشنهاد زمان و پذیرش طرف مقابل با حفظ زمان قبلی |
| متن و فایل جلسه | مالکیت طرفین، زمان و وضعیت جلسه، پذیرش هر دو طرف، ACK فقط پس از commit، شناسه تکرارناپذیر پیام، حفظ متن و retry، فایل خصوصی خارج وب و دریافت کنترل‌شده |
| آرشیو | آرشیو خصوصی طرفین؛ دسترسی مدیر فقط با پرونده شکایت باز، تأییدکننده و ناظر مستقل، هدف، حداکثر ۷۲ ساعت، لغو/انقضا و حسابرسی خواندن؛ بستن پرونده مجوزها را لغو می‌کند |
| عملیات | پرونده پشتیبانی و شکایت، پاسخ و وضعیت، بازخورد دریافت‌کننده جلسه پایان‌یافته، سازمان و عضویت پایه، گزارش شمارش و حسابرسی |
| اعلان و تنظیمات | اعلان خوانده‌شده/نشده، مقصد اعلان‌های عملیاتی، قالب مستقل و سوابق تحویل درون سامانه با جلوگیری از تکرار، تنظیمات عمومی؛ اسرار فقط در فایل خصوصی |
| رابط | فارسی RTL، فونت محلی مجاز، آخرین لوگو، کارت و رنگ کله‌غازی، واکنش‌گرایی، خطا/خالی/انتظار/قطع ارتباط، فرم‌های معمول بدون نیاز به JS، نمایش شمسی و انتخاب روز با fallback میلادی |

منطق هویت خارجی با کلید RSA و پاسخ HTTP مصنوعی **فقط در تست** آزموده شده؛ سرویس برنامه با تنظیم پیش‌فرض، هیچ تأیید مصنوعی نمی‌پذیرد. fixtureهای شرایط ضبط فقط در دیتابیس تصادفی محلی ایجاد و پیش از پیش‌نمایش برداشته می‌شوند. هیچ مسیر عمومی برای ساخت fixture یا نمایش کد OTP وجود ندارد.

## قفل‌های عمدی شما

رزرو عمومی، انتشار شرایط ضبط و شروع جلسه بدون سیاست مصوب بسته‌اند. صفحه تقویم زمان واقعی را نشان می‌دهد ولی رزرو عمومی را فعال نمی‌کند. رزرو داخلی مدیریت، مجوز شروع جلسه بدون شرایط نیست. سورس persistence متن و فایل وجود دارد، اما در نصب پیش‌فرض امکان برگزاری عملیاتی جلسه ندارد.

## وابسته به دسترسی یا سرویس موجودنشده

- TSMS: خاموش. تبدیل send-only انجام شده؛ قرارداد POST با اعتبارنامه و دریافت واقعی کد هنوز تأیید نشده. پاسخ ناشناخته یا timeout تحویل موفق معرفی نمی‌شود و retry خودکار ارسال نداریم.
- Google و Eitaa: خاموش. client/token رسمی و آزمون واقعی رفت‌وبرگشت، SDK ایتا و دسترسی شبکه هاست لازم است. `live_verified` در تنظیم نمونه false است.
- صوت، تصویر، ضبط و توقف/بازیابی رسانه: **پیاده‌سازی عملیاتی نشده**. سرویس رسانه انتخاب نشده و API صدور مجوز رسانه وجود ندارد. نشانگر ظاهری ضبط جایگزین آن نیست. آزمون شروع/قطع/بازیابی زیرساخت رسانه انجام نشده است.
- اعلان بیرونی ایتا، یادآوری زمان‌بندی‌شده و گزارش تحویل بیرونی فعال نشده‌اند. پیامک طبق درخواست شما فقط کد احراز هویت است.
- آزمون cPanel و MySQL 8.0.46 واقعی، SSL/کوکی Secure در دامنه واقعی، پشتیبان/بازیابی هاست، موبایل واقعی و مرورگر داخلی ایتا باقی است. آزمون خودکار DB فعلی MariaDB 10.11 محلی است، نه MySQL هاست.

## محدودیت‌های محصول که تکمیل نهایی محسوب نمی‌شوند

- حالت‌های بلوک ویترین فعلی متن/مرشد/تجربه‌اند؛ طراحی بنر تصویری و همه گونه‌های تزئینی نمونه، و برخی جزئیات ظاهری HTML اولیه کامل بازتولید نشده‌اند.
- جست‌وجو متنی/موضوع/مسئله و مرتب‌سازی دارد؛ مجموعه کامل فیلترهای ترکیبی پیشرفته و رتبه‌بندی پیچیده سند، ابزار مترادف‌ها/برچسب‌ها و گزارش‌های تحلیلی/خروجی گسترده هنوز کامل نیستند.
- تقویم دارای نمایش و انتخاب شمسی در مرورگرهای پشتیبان Intl است؛ ورودی پایه میلادی حفظ شده. همه حالت‌های picker شمسی و آزمون دستگاه واقعی تکمیل نشده‌اند.
- دعوت فعلاً برای حساب موجود است و اعلان درون سامانه می‌سازد؛ ارسال دعوت به فرد بدون حساب و مدیریت انبوه دعوت‌ها ساخته نشده است.
- ادغام تاریخچه دو حساب در محصول وجود ندارد. تعارض متوقف می‌شود؛ فرآیند امن انتقال روش ورود با اثبات هر دو مالکیت در راهنمای هویت توضیح داده شده. نام یا ایمیل ادعایی هیچ‌گاه مبنای ادغام نیست.
- بازیابی اضطراری مدیر پس از گم‌کردن تمام اعتبارنامه‌ها، ابزار انتقال از سامانه قدیمی، تنظیم اسرار از UI و عملیات انبوه پیشرفته ساخته نشده‌اند. تنظیم اسرار فعلی از فایل خصوصی است.
- اسکن بدافزار سرویس مستقلی ندارد؛ نوع/اندازه/پسوند/ابعاد و یکپارچگی فایل بررسی می‌شود و PDF به شکل attachment ارائه می‌شود. ذخیره فایل با باگ مرورگر یا اسکن جامع امنیتی یکسان معرفی نمی‌شود.

فهرست بالا به معنی ادعای تکمیل صددرصد سند نیست. بسته قابل اجرا و توسعه است، اما برای انتشار عمومی همه موارد مسدود و معیارهای پذیرش باید بسته شوند.
