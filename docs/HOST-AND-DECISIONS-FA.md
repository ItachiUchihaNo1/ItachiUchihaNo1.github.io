# شواهد هاست و تصمیم اجرایی

اطلاعات اعلام‌شده کاربر در ۲۰۲۶-۱۰-۱۶:

- MySQL Community Server نسخه `8.0.46-cll-lve` با اتصال محلی UNIX socket.
- charset پیش‌فرض نمایش‌داده‌شده utf8mb3؛ جدول‌ها و اتصال این پروژه صریحاً utf8mb4 هستند.
- PHP phpMyAdmin برابر 8.4.25 و افزونه‌های mysqli/curl/mbstring در همان محیط. نسخه و pdo_mysql خود دامنه‌ها هنوز با این گزارش اثبات نمی‌شود.
- Cron Jobs موجود است.
- Document Root سایت `~/morshedapp.ir` و مدیریت `~/admin.morshedapp.ir` مستقل‌اند. public_html به دامنه اصلی دیگری در همان حساب تعلق دارد.
- وضعیت Force HTTPS Redirect در تصویر فعال نیست؛ وجود و اعتبار گواهی دو دامنه از این گزینه به‌تنهایی نتیجه‌گیری نمی‌شود.

بر این مبنا، هسته ماژولار PHP 8.2+ بدون نیاز به Composer/Node/Terminal در زمان اجرای cPanel و SQL هدف MySQL 8.0 انتخاب شد. برای حساب، مدیریت اولیه و HTTP به VPS یا worker دائمی نیاز فرض نشده است. تست توسعه از PHP 8.4.26 محلی استفاده کرده؛ نسخه PHP دامنه‌ها پیش از نصب باید کنترل شود.

هسته خصوصی sibling ریشه‌هاست. دسترسی سایت و مدیریت به هسته مشترک، نشست و مجوز مشترک ایجاد نمی‌کند. دیتابیس آزمایش از تولید جدا و میان دو ورودی همان محیط مشترک است. ریشه‌های فعلی هاست تغییر نکرده‌اند و ورود به cPanel یا اجرای دستور روی سرور کاربر انجام نشده است.

سرویس ضبط انتخاب نشده و به سرویس رسانه با کنترل انتقال وابسته به سلامت ضبط نیاز دارد. این محدودیت با PHP میزبان حساب حل‌شده اعلام نمی‌شود. رزرو عمومی و انتشار شرایط ضبط طبق دستور کاربر بسته‌اند. تغییر زیرساخت یا خرید سرویس انجام نشده است.

نشان جدیدِ بدون نوشته، مطابق آخرین پیام کاربر جای نشان قبلی در هر دو ریشه قرار گرفت. فایل PNG بدون تغییر، با نسبت ثابت و object-fit:contain استفاده می‌شود. فونت Vazirmatn نسخه v33.003 با مجوز OFL-1.1 از مخزن رسمی، محلی همراه پروژه ارائه شده است؛ بخش هویت برای فونت به CDN وابسته نیست.

منابع رسمی فنی:

- [PHP — امنیت تنظیمات نشست](https://www.php.net/manual/en/session.security.ini.php)
- [MySQL 8 — نصب ZIP و مقداردهی محیط محلی](https://dev.mysql.com/doc/refman/8.0/en/windows-install-archive.html)
- [MariaDB — بسته قابل حمل Windows برای آزمون محلی](https://mariadb.com/docs/server/server-management/install-and-upgrade-mariadb/installing-mariadb/binary-packages/installing-mariadb-windows-zip-packages)
- [Vazirmatn — مخزن و مجوز فونت](https://github.com/rastikerdar/vazirmatn)

دریافت MySQL رسمی برای آزمون این رایانه به صفحه عدم دسترسی دانلود هدایت شد. MariaDB 10.11.14 از آرشیو رسمی دریافت و SHA-256 بسته با checksum منتشرشده تطبیق داده شد؛ فقط در work برای آزمون استفاده شده و بخشی از نصب پیشنهادی هاست یا سورس تحویلی نیست. سرور محلی سرویس سیستم نصب نمی‌کند و فقط روی loopback اجرا می‌شود.
