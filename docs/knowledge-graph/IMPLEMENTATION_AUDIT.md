# تطبیق ساختار موجود با اطلس و گراف دانش

ممیزی پیش از تغییر schema در ۲۹ مهر ۱۴۰۵ انجام شد. PHP 8.2، PDO، MySQL/MariaDB و روتینگ داخلی؛ پایگاه گراف یا ORM موازی اضافه نمی‌شود.

| مفهوم | منبع واقعی موجود | تکمیل لازم |
|---|---|---|
| حساب و نقش مرشد | m_users، m_mentors | بدون حساب تازه برای مرشد/مجموعه |
| تجربه و نسخه انتشار | m_experiences، m_experience_versions، m_experience_details | روابط جدید بر نسخه تجربه نگهداری شوند تا پیش‌نویس به انتشار نشت نکند |
| موضوع/مسئله | m_terms، term_id، m_experience_issues | موضوع چندانتخابی، alias و ادغام، با حفظ لینک قدیمی |
| مجموعه | m_organizations و m_memberships | توسعه همان شناسه‌ها با metadata؛ عضویت عملیاتی قبلی منبع ارتباط عمومی نیست |
| جغرافیا | استان/شهر شخصی در m_user_profiles | مرجع استان/شهرستان مستقل؛ اقامت شخصی هرگز backfill مکان تجربه نیست |
| مشاوره/جلسه | m_bookings، m_booking_details، m_time_proposals، m_booking_events | فقط event خصوصی و غیرمسدودکننده؛ قواعد و gate فعلی حفظ می‌شوند |
| بازخورد و اعلان | m_feedback، m_notifications | عدم انتقال متن خصوصی به گراف |
| حسابرسی | m_audit_logs | استفاده مجدد؛ جزئیات قبل/بعد تصمیم‌های جدید در journal مجزا |
| گراف | وجود ندارد | registry سبک و روابط معنایی جدید؛ روابط اصلی به صورت projection |
| رویداد تحلیلی | شمارنده بازدید و audit | allowlist خصوصی، بدون query خام، IP و شرح شخصی |

## تصمیم‌های تطبیق

مجموعه چندگانه مطابق سند اطلس پشتیبانی می‌شود؛ گراف فقط projection همان پیوندهاست. مالک فعلی تجربه یک مرشد است و بی‌دلیل چندمالک نمی‌شود؛ خروجی مجموعه بر شناسه یکتا شمرده می‌شود. مجموعه‌های قبلی تا بررسی مدیر و وجود تجربه عمومی، عمومی نمی‌شوند. جدول عضویت موجود برای محدودیت سازمانی رزرو محفوظ می‌ماند و به معنای عضویت عمومی مرشد تفسیر نمی‌شود.

اسناد گراف نسخه اول نمایش تصویری شبکه را به آینده موکول کرده‌اند؛ طبق درخواست صریح فعلی، اطلس جغرافیایی در همین نسخه ساخته می‌شود. جغرافیای تأییدنشده یا رشته‌های آزاد موجود به عنوان داده قطعی مهاجرت نمی‌کنند. سیاست نگهداری رویدادها نیازمند مقدار مصوب و قابل تنظیم است؛ جمع‌آوری تحلیلی با پیش‌فرض خاموش و بدون زمان حقوقی فرضی انجام می‌شود.
