# تصمیم‌ها و مرز تحویل

- درخواست فعلی اجرای اطلس را شامل می‌شود؛ موکول‌کردن اطلس در سند گراف، با دستور مستقیم فعلی جایگزین شده است.
- چند مجموعه برای یک تجربه مطابق سند اطلس پشتیبانی می‌شود؛ رابطه‌ها معنا و تأیید مستقل دارند.
- مدل فعلی یک مرشد اصلی برای هر تجربه دارد و این قرارداد حفظ شده است. چندراوی مستقل و تفکیک حقوق مؤلف، نیازمند فاز مشخص جداگانه است.
- هیچ نام یا مکان از سکونت کاربران حدس زده و تأیید نشده است. مدیر باید مجموعه‌های واقعی و مکان تجربه‌های موجود را تکمیل/تأیید کند. صفحهٔ خالی، دادهٔ ساختگی را جایگزین نمی‌کند.
- مرزبندی، مرجع OpenStreetMap است؛ اتصال به مرجع رسمیِ به‌روز تقسیمات کشوری و تطبیق تغییرات بعدی نیازمند منبع رسمی قابل دریافت است.
- گراف تصویری، Neo4j، پیشنهاد هوشمند، استخراج خودکار هوش مصنوعی و تحلیل شبکهٔ پیشرفته طبق محدودهٔ نسخه اول اجرا نشده‌اند.
- سیاست رویدادهای خصوصی پیش‌فرض خاموش است. فعال‌کردن آن به سیاست مصوب، اطلاع‌رسانی مناسب و زمان‌بندی فرمان پاکسازی در هاست نیاز دارد.
- قواعد بسته‌بودن رزرو عمومی تا آمادگی زیرساخت تماس، حفظ شده‌اند. اتاق صوتی/تصویری جدید یا اعلان پیامکی واقعی در این تغییر ساخته نشده است.
- ورود واقعی در برنامک ایتا با دسترسی حساب کاربر قابل تأیید نهایی است؛ نقشه از API دستگاه و مجوز جدید استفاده نمی‌کند و فرم‌های معمولی جایگزین تعامل نقشه هستند.
