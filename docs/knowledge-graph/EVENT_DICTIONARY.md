# فرهنگ رویداد و حریم خصوصی

| رویداد | محرک | دادهٔ افزودهٔ مجاز |
|---|---|---|
| SEARCH_SUBMITTED | نمایش نتایج جست‌وجوی متنی | طول عبارت و نوع نتیجه |
| SEARCH_RESULT_OPENED | بازکردن لینک نتیجهٔ فهرست | جایگاه نتیجه |
| EXPERIENCE_VIEWED | مشاهدهٔ تجربهٔ عمومی | هیچ |
| MENTOR_PROFILE_VIEWED | مشاهدهٔ پروفایل عمومی | هیچ |
| CONSULTATION_REQUESTED | ثبت موفق درخواست | شناسهٔ تجربه در صورت وجود |
| CONSULTATION_CONFIRMED | قبول درخواست | هیچ |
| SESSION_CANCELLED | لغو موفق | هیچ |
| SESSION_COMPLETED | ثبت برگزاری | هیچ |
| FEEDBACK_SUBMITTED | ثبت بازخورد موفق | امتیاز |
| SESSION_STARTED | فقط زیرساخت ارتباطی آینده | فعلاً عمداً ثبت نمی‌شود |

گردآورنده فقط پس از پایان تراکنش کسب‌وکار اجرا می‌شود، actor را از نشست سرور می‌گیرد و شکستش به پاسخ اصلی سرایت نمی‌کند. کلید یکتا از تکرار یک رخداد جلوگیری می‌کند. فیلد نامجاز باعث رد کل رخداد می‌شود. متن جست‌وجو، نیاز خصوصی، تلفن، پیام، IP، رمز و توکن وارد جدول رویداد نمی‌شوند. زمان‌ها UTC/unix هستند. هیچ API عمومی رویداد یا شبکهٔ شخصی ارائه نشده است.

فعال‌سازی در «روابط و فراداده» فقط توسط مدیر سامانه و پس از تصویب سیاست و مدت نگهداری ممکن است. پیش از فعال‌سازی، کار زمان‌بندی‌شدهٔ خصوصی `php morshed-core/bin/knowledge-maintain.php --apply --purge-events` را در هاست تنظیم کنید. پاکسازی هر بار حداکثر ۵۰۰۰ رکورد منقضی حذف می‌کند؛ در حجم بالا دفعات اجرا را افزایش دهید. این فرمان در وب اجرا نمی‌شود. این انتشار سیاست را در محیط واقعی فعال نمی‌کند.
