# تغییرات سازگار داده‌ها — نسخه ۱۵

جداول اصلی و شناسه‌های کاربران، مرشدها، تجربه‌ها، موضوع‌ها، مسائل، مجموعه‌ها و رزروها حفظ شده‌اند. شمارهٔ مهاجرت‌های قبلی ۷ باقی است؛ مانند امکانات قبلی، جدول‌های افزایشی با آماده‌ساز idempotent و پیش از تراکنش کسب‌وکار ایجاد می‌شوند. فایل‌های SQL فقط در هستهٔ خصوصی منتشر می‌شوند.

- `m_places`: مرجع سلسله‌مراتبی استان و شهرستان؛ مکان سکونت کاربر منبع اطلس نیست.
- `m_organization_profiles`, `m_organization_aliases`: تکمیل همان `m_organizations`، تأیید مدیر و ارجاع ادغام؛ بدون حساب مستقل.
- `m_experience_organizations`, `m_experience_places`: روابط وابسته به نسخهٔ تجربه با تصمیم بررسی. انتشار صرفاً نسخهٔ عمومی را می‌خواند. نام خام، مدرک و یادداشت خصوصی به خروجی عمومی منتقل نمی‌شوند.
- `m_experience_topics`: چندموضوعی؛ موضوع اصلی قدیمی همچنان سازگار خوانده می‌شود. `m_experience_issues` قبلی حفظ شده است.
- `m_atlas_changes`: قبل/بعد تصمیم‌های مدیریتی و انتساب‌ها.
- `m_knowledge_entities`: فهرست شناسه‌ها؛ وضعیت و نام از منبع اصلی خوانده می‌شوند.
- `m_knowledge_relations`, `m_knowledge_history`: فقط روابط معنایی تازه، منشأ و تصمیم دارای نسخهٔ خوش‌بینانه؛ روابط قطعی موجود کپی نمی‌شوند.
- `m_term_aliases`, `m_term_redirects`: نام هم‌معنا و ادغام بدون حذف شناسه‌های تاریخی.
- `m_interaction_events`, `m_interaction_policy`: رویدادهای خصوصی مجاز؛ پیش‌فرض خاموش و بدون مدت نگهداری فرضی.

نصب تازه و ارتقای داده‌های موجود هر دو آزموده می‌شوند. بازگردانی شامل کل جدول‌ها و ابطال نشست‌های بازیابی‌شده آزموده شده است. حذف ستون یا بازنویسی محتوا انجام نشده است.
