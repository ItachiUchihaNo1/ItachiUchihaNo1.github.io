# نتایج آزمون به‌روزرسانی اول — ۲۰۲۶/۱۰/۱۷

روی سورس نهایی این به‌روزرسانی، PHP 8.4.26 و یک دیتابیس مستقل و موقت MariaDB 10.11.14 اجرا شد. هیچ پیامک یا اعلان بیرونی ارسال نشد و سرویس واقعی ایتا یا گوگل فراخوانی نشد.

| گروه | نتیجه |
| --- | --- |
| حساب کاربری و امنیت هویت | ۴۰ موفق، صفر شکست |
| محصول، رزرو، نسخه‌ها و ویترین | ۶۸ موفق، صفر شکست |
| ورود خارجی با امضای واقعی آزمایشی و پاسخ سرویس آزمایشی | ۲۴ موفق، صفر شکست |
| اعلان‌ها و تنظیمات | ۱۱ موفق، صفر شکست |
| درخواست‌های HTTP، رقابت هم‌زمان، فایل و بازیابی دیتابیس | ۳۶ موفق، صفر شکست |
| رفتار پیام در اختلال شبکه و تأیید ذخیره | ۴ موفق |
| تولید مستقل کلید و تطبیق SHA256 با WebCrypto | ۲ موفق |
| آماده‌سازی migrationهای دیتابیس آزمایشی | ۱ موفق |

جمع این مجموعه ۱۸۶ بررسی موفق است. ۲۲ دسته‌بندی خطای نصب و آزمون نوشتن امن لاگ خصوصی نیز جداگانه موفق بودند. همهٔ فایل‌های PHP هسته و JavaScript سایت از نظر نحوی بررسی شدند.

## بررسی‌های افزوده‌شده

ویرایش سربرگ و عنوان دلخواه، خصوصی‌ماندن پیش‌نویس، حفظ نسخهٔ عمومی تا انتشار، انتخاب دستی موضوعات، حذف موضوع غیرفعال از ویترین، خالی‌ماندن ردیف پس از حذف آخرین کارت، انتشار صریح ویترین خالی، رد سربرگ تکراری، رد چیدمان نامعتبر، منع ویرایش توسط کاربر عادی، ورود مهمان به ویترین بدون ریدایرکت، وجود پنج آیکون ناوبری، فرم‌های واقعی ورود/ثبت‌نام/OTP و جلوگیری از ایجاد نشست با دادهٔ جعلی ایتا آزموده شدند.

## بررسی واقعی مرورگر

در مرورگر مبتنی بر Chromium، ویترین و ورود در دسکتاپ و عرض موبایل ۳۹۰ پیکسل مشاهده شدند. صفحهٔ موبایل سرریز افقی نداشت. با حساب مدیریت صرفاً آزمایشی، متن سربرگ و حذف آخرین کارت ذخیره شدند؛ عمومی‌بودن نسخهٔ قبلی پیش از انتشار و تغییر واقعی متن و خالی‌ماندن ردیف پس از انتشار بررسی شد. بازیابی نسخهٔ قبلی و ادامهٔ ویرایش همان پیش‌نویس پس از ذخیره نیز بررسی شدند. در صفحات بررسی‌شده خطای JavaScript ثبت نشد.

داده‌های این آزمون در پوشهٔ خصوصی آزمایش بودند و وارد بسته یا گیت‌هاب نشدند.

## مواردی که این نتیجه تأیید نمی‌کند

ورود با توکن واقعی `morshed_app`، رفتار روی نسخهٔ اندروید یا ویندوز خود ایتا، ارسال واقعی TSMS، OAuth واقعی گوگل، نصب این اصلاحات روی cPanel، و اجرای همین آزمون‌ها روی MySQL 8 هاست هنوز انجام نشده‌اند. این نتایج به معنای فعال‌بودن سرویس‌های بیرونی نیستند. رزرو عمومی و سرویس صوت/تصویر/ضبط همچنان مسدود باقی می‌مانند.
