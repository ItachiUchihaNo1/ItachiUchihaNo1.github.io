# نسخهٔ ۳۱ — تاریخ و بازه‌های رزرو

در بررسی رزرو گزارش‌شده مشخص شد زمان ایجاد ۷ آبان و زمان رزرو ۸ آبان است. کد در نبود زمان امروز می‌توانست خودکار نزدیک‌ترین روز آزاد بعدی را انتخاب کند. همچنین تغییر تاریخ/مدت در فرم بالا، بدون فشردن دکمه، گزینه‌های قبلی پایین را باقی می‌گذاشت.

اصلاحات:
- تاریخ انتخابی ثابت می‌ماند؛ نبود زمان آزاد موجب رفتن خودکار به روز بعد نمی‌شود. نزدیک‌ترین روز آزاد فقط یک پیشنهاد صریح است. تاریخ لینک گذشته به امروز برمی‌گردد و اطلاع داده می‌شود.
- تغییر تاریخ یا ۱۵/۳۰ دقیقه، همان لحظه گزینه‌های همان روز را با API سبک تازه می‌کند؛ متن مسئلهٔ واردشده باقی می‌ماند. هنگام دریافت، ارسال و انتخاب گزینه‌های قبلی بسته می‌شود. تاریخ روز روی هر گزینه و بالای فرم مشخص است.
- بازه‌ها از ابتدای برنامهٔ مرشد تولید می‌شوند: برای ۱۴:۰۷ تا ۱۴:۳۷ با استراحت صفر، انتخاب ۱۵ دقیقه دو بازهٔ ۱۴:۰۷–۱۴:۲۲ و ۱۴:۲۲–۱۴:۳۷ می‌دهد؛ ۳۰ دقیقه یک بازه می‌دهد. استراحت تنظیم‌شدهٔ مرشد رعایت می‌شود.
- رزرو در انتظار پاسخِ منقضی‌نشده و رزرو قطعی، همهٔ بازه‌های هم‌پوشان ۱۵ یا ۳۰ دقیقه را حذف می‌کنند. رد، لغو یا انقضا آن را آزاد می‌کند. فرم فعال هر ۲۰ ثانیه و هنگام بازگشت به تب وضعیت را تازه می‌کند؛ کنترل نهایی تحت قفل تراکنش در سرور است.
- ارسال فرم به تاریخ انتخابی مقید شد؛ اختلاف timestamp با selected_date رد می‌شود. فرم قدیمی یا API سازگار همچنان کار می‌کند.
- حداقل فاصله تا جلسه در پنل مرشد با دقت دقیقه (مثلاً ۳۰ دقیقه یا صفر) تنظیم می‌شود. ستون nullable lead_minutes افزایشی است؛ مقدارهای قدیمی ساعتی تا تغییر صریح حفظ می‌شوند. CHECK قدیمی و مهاجرت‌های پیشین دست‌نخورده‌اند. مقدار lead_hours برای API قدیمی معتبر می‌ماند. زمان‌های فاقد فرصت حداقلی پذیرش ارائه نمی‌شوند.
- انتخاب ۱۵/۳۰ دقیقه و استراحت در پنل مرشد، پیش‌نمایش بازه‌ها را هم به‌روز می‌کند.

آزمون‌ها: مجموعهٔ کامل رگرسیون محلی و ۵۵ بررسی HTTP/رقابت، نصب تازه/بازیابی، چت و عضویت موفق شدند. ۱۷ بررسی اختصاصی شامل مبدأ ۱۴:۰۷، طول ۱۵/۳۰، حذف تداخل، رد درخواست هم‌زمانِ زمان گرفته‌شده، آزادسازی، تاریخ ثابت، اعتبارسنجی تاریخ، استراحت و سازگاری زمان ساعتی/دقیقه‌ای موفق شدند. API سبک با HTTP واقعی بررسی شد. در مرورگر، تغییر ۳۰ به ۱۵ بدون بارگذاری صفحه سه زمان آزاد نشان داد و زمان رزروشدهٔ ۱۴:۲۲ حذف بود؛ متن فرم حفظ شد. تغییر به امروزِ بدون برنامه، همان ۷ آبان ماند و ارسال بسته شد.
