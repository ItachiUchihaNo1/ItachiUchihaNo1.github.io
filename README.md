# مرشد — سورس سایت اصلی

این مخزن نسخهٔ پایهٔ PHP سایت مرشد برای اصلاح مرحله‌ای بخش‌های سایت اصلی است. در این مرحله ورودی و دارایی‌های عمومی پنل مدیریت بارگذاری نشده‌اند؛ هستهٔ مشترک و مدل دیتابیس موجود حفظ شده‌اند و بازطراحی مدیریت در محدودهٔ این مرحله نیست.

## مشاهده و اجرا

GitHub Pages کد PHP، ورود و دیتابیس MySQL را اجرا نمی‌کند. برای مشاهدهٔ نسخهٔ واقعی از محیط محلی PHP یا هاست cPanel استفاده کنید. این مخزن در حال حاضر پیش‌نمایش HTML یا شبیه‌سازی ورود ندارد.

- `morshedapp.ir/`: فایل‌های Document Root سایت اصلی.
- `morshed-core/`: هستهٔ خصوصی؛ باید بیرون از همهٔ Document Rootها قرار گیرد.
- `morshed-core/config/local.example.php`: نمونهٔ تنظیمات بدون اطلاعات محرمانه. نسخهٔ واقعی `local.php` تنها روی سرور ساخته می‌شود.
- `morshed-core/database/migrations/`: تغییرات نسخه‌بندی‌شدهٔ دیتابیس مشترک.
- `docs/INSTALL-CPANEL-FA.md`: راهنمای نصب قبلی کل محصول؛ بخش مدیریت آن برای مرحلهٔ بعد است.
- `docs/STATUS-FA.md`: وضعیت قابلیت‌ها و محدودیت‌های نسخهٔ موجود.

## محدودهٔ تغییرات

ابتدا فقط مشکلات اعلام‌شدهٔ سایت اصلی اصلاح می‌شوند. سپس پنل مدیریت جداگانه بررسی می‌شود. دیتابیس از ابتدا مشترک طراحی شده است؛ نیازی به ساخت دو دیتابیس محصول و ادغام بعدی نیست.

اطلاعات واقعی دیتابیس، کلیدها، نشست‌ها، آرشیوها و محتوای کاربران در این مخزن قرار نمی‌گیرند. هنگام به‌روزرسانی cPanel، فایل خصوصی `local.php` و پوشهٔ ذخیره‌سازی موجود باید حفظ شوند. فایل نصب کامل SQL فقط برای دیتابیس خالی است؛ روی دیتابیس موجود تنها migrationهای اجرا‌نشده اعمال می‌شوند.

رزرو عمومی و انتشار شرایط ضبط طبق تصمیم فعلی مسدود می‌مانند. اتصال واقعی ایتا پس از بررسی مستندات مورد تأیید و آزمون سرویس بررسی خواهد شد. ارسال واقعی پیامک و ورود خارجی تا زمان تنظیم و آزمون سرویس، عملیاتی اعلام نمی‌شوند.

آزمون‌های مستندشده مربوط به نسخهٔ پایه هستند؛ این بارگذاری صرفاً انتقال سورس است و به معنی استقرار یا آزمون جدید روی هاست نیست.
