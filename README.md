# دموی رابط کاربری «شبکه تجربه هیأت» — مدل ۳

این مخزن فقط برای **تأیید ظاهر و تجربه کاربری** ساخته شده است. در این مرحله هیچ OTP، دیتابیس، سرور، پیامک یا API واقعی متصل نیست و همه داده‌ها نمایشی هستند.

## اجرای محلی

فایل `index.html` را مستقیم در مرورگر باز کنید، یا برای اجرای محلی بهتر:

```bash
python -m http.server 8080
```

سپس آدرس زیر را باز کنید:

```text
http://localhost:8080
```

## انتشار روی GitHub Pages

1. یک Repository جدید در GitHub بسازید.
2. فایل‌های این پوشه را در شاخه `main` آپلود یا push کنید.
3. وارد `Settings > Pages` شوید.
4. در بخش `Build and deployment`، گزینه `Source` را روی **GitHub Actions** قرار دهید.
5. Workflow موجود در `.github/workflows/pages.yml` به‌صورت خودکار دمو را منتشر می‌کند.
6. چند دقیقه بعد لینک سایت در همان صفحه Pages نمایش داده می‌شود.

هر بار که روی شاخه `main` تغییر جدید Push شود، نسخه نمایشی دوباره Deploy خواهد شد.
