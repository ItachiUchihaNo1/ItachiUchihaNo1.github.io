# مرشد — بسته اجرایی PHP / cPanel

این سورس شامل سایت فارسی، مدیریت مستقل، هسته مشترک و دیتابیس واقعی است. نسخه جاری schema **6** دارد. این بسته روی هاست شما نصب نشده است. انتشار عمومی رزرو و شرایط ضبط مطابق دستور شما بسته است؛ صوت و تصویر سرویس عملیاتی ندارند. اتصال‌های TSMS، گوگل و ایتا بدون تنظیم خصوصی و آزمون واقعی خاموش‌اند.

## از کجا شروع کنید؟

۱. ابتدا `docs/START-HERE-FA.md` را بخوانید؛ سپس `docs/INSTALL-CPANEL-FA.md` را برای نصب آزمایشی دنبال کنید.
۲. وضعیت دقیق قابل‌استفاده، مسدود و ناتمام در `docs/STATUS-FA.md` آمده است. وجود سورس اتصال، اثبات کارکرد سرویس واقعی نیست.
۳. راهنمای کار با مدیریت و مرشد در `docs/USER-GUIDE-FA.md` است.

## اجزای بسته

- `morshedapp.ir/`: فقط فایل‌های عمومی سایت اصلی.
- `admin.morshedapp.ir/`: فقط فایل‌های عمومی پنل مدیریت.
- `morshed-core/`: هسته خصوصی، تنظیمات نمونه، قالب‌ها، migrationها و محل فایل‌ها و نشست‌های خصوصی.
- `docs/`: راهنما، معماری، آزمون و موارد ناتمام.
- `tools/`: ساخت کلید آفلاین، probe محیط و بسته‌بندی؛ روی Document Root آپلود نشوند.
- `tests/`: آزمون‌های توسعه. داده آزمون فقط در دیتابیس تصادفی محلی ساخته می‌شود؛ نصب واقعی هیچ حساب، شماره تأییدشده یا محتوای ساختگی وارد نمی‌کند.

PHP 8.2+ و MySQL 8 هدف استقرارند. `pdo_mysql` لازم است؛ cURL و OpenSSL برای اتصال‌ها و fileinfo برای فایل لازم‌اند. Node و Python فقط ابزار توسعه و آزمون‌اند و در هاست نیاز نیستند. فریم‌ورک یا وابستگی Composer نصب‌نشده‌ای وجود ندارد.

## نصب تازه و ارتقا

برای DB تازه، فایل `morshed-core/database/install-new-database.sql` را فقط یک بار وارد کنید. برای DB دارای migration 001، فقط migrationهای **002 تا 006** به‌ترتیب اعمال شوند. تغییرات DDL را دارای rollback تراکنشی فرض نکنید؛ پیش از ارتقا پشتیبان بگیرید. راهنمای نصب جزئیات دو دامنه، مسیر خصوصی، ساخت اولین مدیر و Cron را دارد.

شناسه و رمز پیش‌فرض برای بهره‌برداری وجود ندارد. کلیدها در `config/local.php` خصوصی قرار می‌گیرند؛ این فایل در بسته و مخزن نیست.
